# 📅 Smart Time Management App

A web-based application that helps users, especially students and professionals, manage their time effectively with task scheduling, reminders, and chatbot support.

## 🚀 Features

- User registration and login system  
- Create, edit, and delete tasks  
- Daily and weekly schedule view  
- Smart reminders for upcoming tasks  
- Chatbot for quick scheduling support  
- Multilingual support (English, Vietnamese)  
- Responsive design for desktop and mobile

## 🛠️ Tech Stack

- **Front-end:** HTML, CSS, JavaScript  
- **Back-end:** Node.js (Express)  
- **Database:** JSON (or can be extended to MongoDB/Firebase)  
- **Other tools:** Bootstrap, SweetAlert, LocalStorage
